### Downloads screen

The downloads screen is rebuilt in the shape of Chrome's: a header with a single
"Using X of Y in <location>" label, and rows showing a file icon, the file name and a
"size · domain" subtitle.

Multi-select deletion is in: a long press enters the selection mode, "Select all" picks
everything, the header counts what is selected ("Delete (n)"), and "Delete all" clears
the list — every deletion asks for a confirmation first. A download whose size does not
fit on the destination is blocked before it starts, and the storage summary is refreshed
when a download completes.
